## 👨‍💻 About Me

I specialize in building **fault-tolerant distributed systems**, **enterprise-grade full-stack web applications**, **autonomous agentic AI workflows**, and **cryptographic zero-trust security platforms**. My engineering focus centers on clean system design, concurrency optimization, zero-leak credential hygiene, resilient architectural fallbacks, and production-grade Docker containerization.

- 🔭 **Architecting:** Real-time log streaming pipelines, multi-tenant webhooks, and distributed rate limiting engines in **Go**.
- 🤖 **Pioneering AI:** Multi-agent orchestrations with **LangGraph**, **Gemini API**, **FLUX.1**, and clinical decision support engines.
- 🔒 **Securing Systems:** Zero-trust reverse proxies, AST-based static vulnerability scanners, and AES-256-GCM zero-knowledge stores.
- 🌐 **Full-Stack Engineering:** High-performance web applications using **Next.js 16 (Turbopack)**, **React 19**, **TypeScript**, **PostgreSQL**, and **MongoDB**.
